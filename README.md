# Reybar Carta v2

Versión experimental separada de la carta actual.

## Ejecutar

```bash
npm install
npm run dev
```

Para comprobar la versión final:

```bash
npm run build
npm run preview
```

## Cambiar platos y precios

Edita solamente `src/data/menu.ts`. La portada, el modal y la cuadrícula se actualizan automáticamente a partir de esa fuente.

Esta versión conserva la carta publicada en `carta-men--reybar` sin modificarla.
